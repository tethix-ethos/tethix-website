# Tethix Privacy Policy

{: .subtitle}
Approximate readtime: 1 min

## The short version

Tethix (2020–2025) is no longer active, and this website is now a **static archive** kept for posterity. It collects no personal data.

## When you browse this website

This site is a static website hosted on GitHub Pages. It sets no cookies, runs no analytics, and uses no tracking pixels. We collect nothing when you browse.

Because the site is served by GitHub Pages, GitHub may log standard technical data (such as IP addresses) to deliver and secure the service — see [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Some pages link out to external services — the archived [Substack newsletter](https://tethix.substack.com/), podcast platforms, YouTube, Vimeo, and the preserved [ETHOS seedling app](https://ethos.tethix.co/) (which itself requires no account and collects no personal data). Those services have their own privacy policies, which apply when you follow those links.

## When you send us an email

Email addresses on this site are provided for questions about the archive. Emails we receive are managed by ProtonMail; message content is encrypted, and ProtonMail processes some metadata (sender/recipient addresses, originating IP, subject line, timestamps). You can learn more in ProtonMail's [Privacy Policy](https://proton.me/legal/privacy).

## What happened to previously collected data

While Tethix was active, we collected limited personal data with consent — newsletter subscriptions, workshop participation, website comments — under an earlier version of this policy. The newsletter now lives on Substack (dormant; no new emails are sent), the co-design tools and comment systems are no longer in use, and the associated WordPress-era hosting has been retired.

If you have any questions about data from that era, or about this policy, please contact us [via email](mailto:data@tethix.co).
